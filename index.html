02 — Approach

Three rules I build by.

  1. 01

    Make the model explicit

    Every output traces back to a formula, an invariant or a bound. If the channel count cannot be proven minimal, the tool reports the gap instead of implying certainty.

  2. 02

    Attack the adversarial path

    Partitions, reordered operations, deletes that overtake inserts, interrupted merges. The interesting bugs live where the happy path ends, so the tests go there first.

  3. 03

    Skip the dependency tax

    These engines are standard-library only and small enough to read in an afternoon. Fewer moving parts, clearer failure modes, no supply chain to audit.

03 — Interactive

Plan a radio field in the browser.

Atlas Studio is a client-side workbench for co-channel planning. It builds the interference graph, assigns channels with DSATUR, reports the clique lower bound, and paints the SINR map — all from the same model as the command-line planner.

  • Drag sites and watch the graph re-colour
  • Share a plan as a URL, export SVG or JSON
  • No server round trips: the model runs in your tab
